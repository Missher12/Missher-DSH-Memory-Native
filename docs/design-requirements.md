# 记忆面板设计需求（视觉规范 v1）

> 本文档是 UI 的唯一验收依据。以后任何界面改动：**先更新本文档 → 再改代码 → 夹具截图对比 → 最后 HMR 推送**。
> 目标：紧凑、单行优先、折行即铺满、同一套卡片规格、深浅色一致、窄宽可用。

## 1. 布局原则

1. **单行优先**：一行放得下就绝不折行；控件宽度允许收缩，但不允许文字竖排或被截成两行。
2. **折行即铺满**：必须折行时，第二行要占满整行（不允许“左边空一大片、右边两个按钮”）。
3. **同规格卡片**：所有卡片 = 12px 圆角 + 0.5px 边框 + 14px 内距 + 同背景。
4. **信息层级固定**：标题 13/600 → 正文 13/400 → 次要 12/400 → 标签 11/500。
5. **胶囊不缩**：类型、状态、标签胶囊一律 `flex: 0 0 auto; white-space: nowrap`，绝不竖排。
6. **长文本单行省略**：列表与画像语句单行 + 省略号 + `title` 悬停全文；需要完整内容时进入编辑弹窗。
7. **窄宽可用**：430px 下无横向滚动；筛选项换两行、洞察条 2×2、指标卡 2×2。

## 2. 基础变量

| 项 | 值 |
|---|---|
| 间距 | 4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 28 |
| 卡片内距 | 14 |
| 卡片间距 | 14 |
| 行内 gap | 6–10 |
| 圆角 | 卡片 12、控件 7、胶囊 5–6、热力格 2 |
| 边框 | 0.5px，`--dsw-alias-border-l2`；卡片背景 `--dsw-alias-bg-layer-3` |
| 字号 | 大数字 24/600（tabular）；标题 13/600；正文 13/400；次要 12/400；标签 11/500；极小 10–11 |
| 主按钮 | 品牌色背景 + 白字；次按钮白底 + 边框；悬停亮度 +5% |

类型色（用于左色条、类型胶囊、画像类型）：

| 类型 | 色 | 胶囊背景 |
|---|---|---|
| 偏好 preference | `#2f6df6` | 12% 透明 |
| 事实 fact | `#0d7f8c` | 12% 透明 |
| 决策 decision | `#6d4aff` | 12% 透明 |
| 片段 episode | `#b7791f` | 12% 透明 |

状态：生效 = success 色 + 12% 背景；待审 = warn 色 + 12% 背景；归档/已取代 = 次要色。

## 3. 组件规格

### 3.1 指标卡
- 4 列等宽（窄宽 2×2），数字 24/600、标签 12 灰色。
- **卡片内不再显示捕获/注入状态胶囊**（状态属于设置项，不占指标卡空间）。
- **选定 C（主次分卡）**：指标区 = 两张并排卡片，同一套卡片规格：
  - 左卡「主指标」：生效 / 待审 / 总计 / 项目，4 列等宽；
  - 右卡「洞察」：连续天数 / 活跃天数 / 近 7 天 / 平均置信度，2×2。
- **字体绝对统一**：两张卡的数值都用 **20/600（行高 28）**，标签都用 **12/400（行高 18）**；
  不再出现 24 与 15 混用（旧版主指标 24、洞察 15 已废弃）。
- **两张卡内部用同一套指标样式**（不能一张“数值+标签同行”、另一张“上下堆叠”）：
  - ≥620px：两张卡都「数值 + 标签同行」；左卡 4 列，右卡 2×2；
  - 480–620px：两张卡都「数值在上、标签在下」；左卡 2×2，右卡 2×2；
  - <480px：两卡堆叠，恢复同行。
- 两卡同高（stretch），左卡 1.6 份宽、右卡 1 份宽；间距 14。**左右并排一直保持到 480px**：
  - ≥620px：左卡 4 列，右卡 2×2（数值与标签同一行）；
  - 480–620px：左卡 2×2；右卡 2×2 但数值在上、标签在下（窄卡放得下）；
  - <480px：两卡上下堆叠，恢复数值与标签同行。

### 3.2 记忆活动卡
- 头部一行：标题 + 配色按钮 + 每日/每周/累计 分段控件。
- 热力图 53 列 × 7 行，格子 2px 圆角、3px 间距；月份标签 9px。
- 活动卡只放热力图 + 月份标签 + 稀疏提示；洞察数据统一放在指标卡第二行，避免两处重复。
- 数据稀疏时显示一行 11px 灰色提示。

### 3.3 用户画像卡
- 头部：标题「用户画像」+ 右侧「共 N 条」。
- 每行：`[类型胶囊] [语句 flex-1 单行省略] [证据数 · 置信度]`。
- 胶囊固定宽、不换行；元信息右对齐、不收缩；语句 `min-width: 0` + ellipsis + title。
- 最多 3 行；无画像时整卡不渲染。

### 3.4 筛选卡
- ≥560px：单行网格 `3 个筛选项 + 搜索(1.6fr) + 刷新 + 重建索引`，铺满整行。
- <560px：两行网格——第一行 3 个筛选项等宽；第二行搜索占 2/3，两个按钮各占一半填满剩余。
- 标签 11px 在控件上方；控件高 28。

### 3.4b 记忆设置卡
- 位置：画像卡下方、筛选卡上方。
- 使用与其他区块一致的卡片容器：12px 圆角、0.5px 边框、14px 内距、bg-layer-3 背景。
- 头部：标题「记忆设置」+ 右侧「上次自维护：归档 n / 备份 日期」摘要。
- 分组，每组带小标题；组间 18px 留白 + 细分隔线，组内行间 0：
  - 「捕获与注入」：自动捕获（开关）、上下文注入（开关）、注入预算（数字 100–8000）。
  - 「保留与维护」：片段保留（数字 0–36500 天）、自维护（开关）。
  - 「数据」：导出 / 导入 / 立即备份 三个次按钮单独成组，不与设置项混排。
- 每项占一行：名称在左、控件在右（右对齐），行高固定 36px（含分隔线，边框计入盒模型）；窄宽 <520 仍保持左名右控件，不换行。
- 所有控件统一 28px 高（输入框、下拉、按钮均 `box-sizing:border-box`），设置行统一 36px；分组标题统一 18px 行高，避免 1px 级高低差。
- 卡片底部单独一行主按钮「保存设置」，与上方设置组留 18px。
- 保存/导出/导入/备份都有状态提示；导入接受本插件导出的 JSON（`{schemaVersion, global, projects}`），按 revision 去重合并，导入后重建索引并刷新列表。
- 设置写入 `~/.dsh/dsh-memory/settings.json`，重启仍生效。

### 3.5 列表卡
- 左侧 2px 类型色条；头部 [类型胶囊][状态胶囊][右对齐 置信度·时间]。
- 正文 13px；底部 [标签左][操作右]。
- 卡片间距 10；无列表时显示空态文案。

### 3.6 页签 / 分页
- 类型页签：胶囊按钮，选中 = 主色底白字，未选 = 白底边框；计数 11px、70% 不透明度。
- 分页条：左「第 x / y 页 · 共 n 条」，右「每页 10/20/50 + 上一页/下一页」。

### 3.7 编辑弹窗
- 12px 圆角、8px 24px 阴影、遮罩 40% 黑；输入框高 32、圆角 8；主按钮 保存、次按钮 取消；Esc 关闭。

## 4. 交互状态

- 悬停：按钮/页签背景 `bg-layer-2`；卡片本身不放大、不位移。
- 焦点：2px 主色 outline，offset 1–2px。
- 禁用：透明度 0.45，禁用态不触发请求。
- 空态：标题 + 一句引导；错误态：红色边框卡片 + 重试按钮，不白屏。

## 5. 响应式

| 宽度 | 行为 |
|---|---|
| ≥620 | 指标 4 列、工具栏单行 |
| 560–620 | 指标 4 列、工具栏单行（收缩搜索框） |
| <560 | 指标 2×2、工具栏两行铺满、洞察条 2×2 |
| 430 | 最小可用宽度，无横向滚动 |

## 6. 验收清单（每次 UI 改动逐条过）

- [ ] 没有文字竖排（类型/状态/标签胶囊宽度 > 文字宽）
- [ ] 没有控件被截成两行或溢出卡片
- [ ] 所有卡片圆角/边框/内距/背景一致
- [ ] 折行时第二行铺满，无大块空档
- [ ] 浅色、深色下文字对比度足够
- [ ] 430px 无横向滚动
- [ ] 空态、错误态、加载态正常
- [ ] 键盘 Esc 可关弹窗、焦点可见
- [ ] 夹具截图与真机效果一致

## 7. 变更流程

1. 修改本文档（写清组件/尺寸/状态变化）。
2. 改 `client.js`（样式与结构）。
3. 用 `design-demos/` 或 `/tmp/dsh-memory-harness` 渲染截图，对照第 6 节。
4. 通过后 touch `client.js` 走 HMR，让用户在真实页面确认。
5. 把结果记入 `docs/verification.md`。

## 8. 已知坑与回归清单（犯错一次就记在这里）

| # | 坑 | 规则 |
|---|---|---|
| 1 | 用 `@media` 看视口宽度，而设置页容器很窄 | 面板一律用 `@container` 容器查询，断点看 `.dsh-memory-root` 的实际宽度 |
| 2 | 只在 demo 宽度（735）验证，真机（约 520）堆叠了 | 每轮必须验证 **735 / 560 / 520 / 430** 四档 |
| 3 | 状态胶囊文字太长把自己挤到第二行 | 胶囊 `flex:0 0 auto; white-space:nowrap`；指标卡不放状态胶囊 |
| 4 | 类型/状态胶囊在 flex 行里被压成两行（「偏 好」竖排） | 胶囊固定宽度 + nowrap；430px 下仍为 34×20 |
| 5 | 两张指标卡字体/排版风格不一致（一张 24 一张 15、一张同行一张堆叠） | 两卡共用同一档字号与同一指标布局规则（见 §3.1） |
| 6 | 长文本把布局撑坏 | 行内文本一律 `min-width:0` + 单行省略 + `title` 全文 |
| 7 | 改 CSS 字符串数组时插入了换行/空串，生成非法 JS | 只做整条规则的字符串替换；改完立刻 `node --check` |
| 8 | 改完不截图就交给用户 | 先夹具截图对比 §6 验收清单，再 HMR 推送 |

### 回归清单（每次改 UI 必跑）

### 3.4c 记忆设置重造（demo 先行，2026-11-02）
- 流程：先出独立 HTML demo（本文件同目录 `demo/memory-settings/index.html`），确认视觉与交互后再接回面板客户端。
- 结构：卡片容器；头部标题 + 上次自维护摘要 + 自动维护状态徽标；三组（捕获与注入 / 保留与维护 / 数据），每组标题 + 行；底部状态行 + 保存按钮。
- 行：统一 48px 高，名称左、控件右；组内细分隔线，组间 20px 留白 + 分隔线。
- 控件：开关 40×22（滑块动画）；数字输入 32px 高、带单位后缀；数据按钮 32px；保存按钮 32px。
- 状态：未保存（底部提示 + 保存可用）、保存中（按钮禁用）、已保存（时间戳，localStorage 持久化）。
- 数据：导出下载 JSON、导入读取 JSON 并提示条数、备份提示路径；反馈用 toast。
- 演示页自带宽度切换（735/520/430）与明暗主题，便于逐档验收。

# Obsidian 阅读体验 Demo

这是一份可直接用 Obsidian 打开的**虚构示例库**。项目、对话、数字均用于演示，未复制个人库正文，也没有可导入为真实记忆的 `dsh_memory` / `dsh_knowledge` 标记。

用 Obsidian 的“打开文件夹作为仓库”选择本目录，再打开 [[首页]]。也可以将发布页的 Demo 压缩包解压后作为独立仓库打开。

目录参考“按用途组织”的笔记习惯：场景 → 知识库 → 工作流 → 决策 → 日记与原始记录。点击双链，或打开反向链接查看出处。

建议按这条线体验：[[首页]] → [[示例图库的备份方案]] → [[调整备份时间的决定]] → [[2026-11-10]]。

本 Demo 是编辑过的体验样板。当前插件会自动生成 `阅读/首页`、按用途/项目汇集的阅读页、主题索引和来源链接；**尚不会自动写出 Demo 中这种连贯的场景说明、工作流或日记**。这些能力要在主题归并、逐段证据和用户手写内容保护完善后再推进。

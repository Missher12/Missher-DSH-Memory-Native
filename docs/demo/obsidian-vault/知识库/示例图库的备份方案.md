# 示例图库的备份方案

## 当前怎么运行

图库先完成夜间照片导入，再创建快照。当前约定是每天 **02:40** 创建一份备份，保留 **21 天**。时间和保留期限是两个独立约定：本次只改了时间，没有缩短可恢复的历史。

依据：[[备份时间]]、[[保留期限]]。

## 为什么不是原来的 02:00

最初的 02:00 快照可能赶在导入结束前执行，导致当天新增照片只进入下一次备份。团队因此把快照移到 02:40，给导入留出时间。

完整决定与原始对话见 [[调整备份时间的决定]] → [[2026-11-10]]。

## 需要恢复时

先确认需要恢复的日期，再把快照恢复到临时目录。核对照片数量及文件可读性后，才能决定是否替换工作目录。步骤见 [[恢复一份备份]]。

这份流程用于 [[夜间导入与恢复]] 场景。它没有授权覆盖当前工作目录。

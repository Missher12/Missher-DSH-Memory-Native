# 调整备份时间的决定

**状态：已确认的演示决定** · 2026-11-10

## 决定

将每天的快照时间从 02:00 调整为 02:40，保留期限维持 21 天。

## 原因

夜间导入有时到 02:20 才结束，原来的快照时间会漏掉本轮新增照片。此次修改解决时序冲突，不涉及保留期限。

# 记忆设置 · 设计预览 demo

独立单文件 demo，不连接真实记忆库，用于确认视觉与交互后再接回面板。

## 打开

```bash
cd demo/memory-settings
python3 -m http.server 64420 --bind 127.0.0.1
# 打开 http://127.0.0.1:64420
```

也可以直接用浏览器打开 `index.html`（下载导出功能在 `file://` 下同样可用）。

## 可交互

- 三个开关（自动捕获 / 上下文注入 / 自维护）与两个数字输入，修改后底部显示「有未保存的更改」，保存按钮可用。
- 保存：模拟 520ms 请求，成功后显示时间并写入 localStorage，刷新后保留。
- 导出：下载示例 JSON；导入：读取 JSON 并提示条数；备份：提示备份路径。
- 顶栏「735 / 520 / 430」切换预览宽度，「深色 / 浅色」切换主题。

## 规格

- 卡片：0.5px 边框、14px 圆角、20px 内距。
- 行高统一 48px；开关 40×22；数字输入 32px；按钮 32px。
- 三组：捕获与注入 / 保留与维护 / 数据；分隔线紧贴行边界（行内容正好居中于上下两条线之间），组标题上方留 22px，组内行间细分隔线。
- 底部统一状态行 + 保存按钮。
